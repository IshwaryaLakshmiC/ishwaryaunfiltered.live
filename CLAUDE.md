# CLAUDE.md

## Purpose

This repository contains the source code and content for my personal portfolio website.

The goal is not to optimise for a single role.

Instead, the portfolio should communicate one clear message:

> I build, design and explain complex cloud systems.

It should naturally appeal to hiring managers across:

- Platform Engineering
- Cloud Infrastructure
- Cloud Architecture
- Observability
- Solutions Engineering
- Technical Leadership

without explicitly targeting any one of them.

---

## Principles

Prioritise:

- Technical depth
- Architectural thinking
- Clear communication
- Simplicity
- Credibility

Avoid:

- Buzzwords
- Marketing language
- Keyword stuffing
- Artificial personal branding
- Claims without evidence

Everything shown should be supported by real work, production experience or demonstrable projects.

---

## Review Philosophy

When reviewing this portfolio:

Challenge everything.

Do not preserve existing wording because it already exists.

Question:

- page structure
- information hierarchy
- recruiter experience
- technical credibility
- readability
- storytelling
- evidence
- visual flow

Recommend removals whenever something weakens the portfolio.

---

## Portfolio Goal

After spending 3 minutes on this website, a hiring manager should think:

> This engineer understands distributed systems, communicates clearly, and can design complex cloud platforms.

---

## Default Behaviour

When making changes:

1. Explain the reasoning.
2. Suggest improvements.
3. Prefer removing over adding.
4. Keep the portfolio concise.
5. Maintain consistency across all pages.
